# 1Web

Página web de prácticas — Aplicaciones Web (IAW), 2º ASIR.

## Descripción
Landing page "Hola Mundo" con estilos y animaciones CSS.

## Estructura
- `index.html` — página principal
- `contacto.html` — página de contacto (añadida vía Pull Request)

## Cómo verlo
Abre `index.html` en un navegador.

## Integración IA ↔ Git ↔ GitHub
Parte de este repositorio se gestiona mediante una IA (Claude) conectada a GitHub:
interpreta el estado del repo, propone y realiza commits, y abre Issues y Pull
Requests de forma supervisada. Los commits de la IA van firmados como "Claude (IA)".
